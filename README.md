# 💚 UBS Conecta IA

### Priscila Ferreira Dias Santos
### Assistente Virtual Inteligente da UBS Maria José Ferreira

O **UBS Conecta IA** é um projeto de assistente virtual desenvolvido para facilitar o acesso da comunidade às informações sobre os serviços oferecidos pela Unidade Básica de Saúde Maria José Ferreira, localizada no povoado Morro do Chupé, em São Raimundo das Mangabeiras, Maranhão.

A solução utiliza Inteligência Artificial para oferecer respostas rápidas, claras e acessíveis, contribuindo para aproximar a população dos serviços de saúde.

## 🎯 Objetivo do Projeto

Desenvolver um assistente virtual capaz de orientar os usuários sobre os serviços, horários de funcionamento, profissionais, vacinação, consultas e demais informações relacionadas à UBS.

O projeto busca melhorar a comunicação entre a unidade de saúde e a comunidade, tornando o acesso à informação mais simples e eficiente.

## 🚀 Funcionalidades

* Informações sobre horários de funcionamento da UBS.
* Consulta à escala de atendimento dos profissionais.
* Informações sobre consultas médicas e odontológicas.
* Orientações sobre vacinação.
* Informações sobre exames preventivos.
* Orientações sobre pré-natal e puericultura.
* Informações sobre testes rápidos.
* Orientações sobre a retirada de medicamentos na farmácia básica.
* Respostas automatizadas utilizando Inteligência Artificial.

## 🛠️ Tecnologias Utilizadas

| Tecnologia          | Finalidade                                                |
| ------------------- | --------------------------------------------------------- |
| n8n                 | Automação e integração do fluxo de atendimento            |
| Claude (Anthropic)  | Processamento de linguagem natural e geração de respostas |
| Cohere              | Geração de embeddings para busca semântica                |
| Simple Vector Store | Armazenamento e recuperação de informações                |
| RAG                 | Consulta à base de conhecimento da UBS                    |
| GitHub              | Versionamento e armazenamento do projeto                  |

## 🧠 Como Funciona

O assistente utiliza uma arquitetura baseada em RAG (Retrieval-Augmented Generation), que permite consultar uma base de conhecimento específica antes de elaborar suas respostas.

O funcionamento ocorre da seguinte maneira:

1. O usuário envia uma pergunta pelo chat.
2. O n8n recebe a mensagem.
3. O agente de Inteligência Artificial interpreta a solicitação.
4. O sistema consulta a base de conhecimento da UBS.
5. As informações relevantes são utilizadas para elaborar uma resposta.
6. O usuário recebe a orientação diretamente no chat.

## 🔒 Segurança e Responsabilidade

O UBS Conecta IA tem finalidade exclusivamente informativa e não substitui o atendimento realizado pelos profissionais de saúde.

O sistema não realiza diagnósticos, não prescreve medicamentos e não substitui consultas ou avaliações clínicas.

As informações disponibilizadas devem respeitar a privacidade dos usuários e os princípios de proteção de dados pessoais.
